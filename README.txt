SMART BILLING & INVENTORY MANAGEMENT SYSTEM

Technology:
Java 17, Swing GUI, MySQL, Maven

Default login:
Username: admin
Password: admin123

Database:
1. Install MySQL.
2. Run database/smartbilling.sql in MySQL Workbench.
3. Open src/main/java/com/smartbilling/DBConnection.java
4. Change DB_USER and DB_PASSWORD if required.
5. Import this Maven project in STS/Eclipse:
   File > Import > Existing Maven Projects
6. Run Main.java.

Features:
- Admin login
- Dashboard
- Product management
- Customer management
- Billing
- Sales history
- Stock tracking
- Low-stock indicator
